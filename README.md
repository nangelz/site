# Luna Pet Care

Landing page funcional e responsiva criada para um pet shop fictício com identidade visual moderna, conteúdo semântico e interatividade básica.

## Estrutura do projeto

- `index.html` — página única com seções de destaque, sobre, serviços e contato.
- `main.css` — estilos responsivos, layout com grid/flexbox, uso de tipografia externa e identidade visual acolhedora.
- `app.js` — validação de formulário na camada de front-end.

## Funcionalidades

- Navegação por seções com links de âncora.
- Seção de destaque com CTA e elementos sobrepostos.
- Seção sobre com indicadores e texto institucional.
- Seção de serviços com cards visuais e `aspect-ratio`.
- Formulário de contato com validação básica de campos e feedback ao usuário.

## Como usar

Abra `index.html` em um navegador. O formulário funciona localmente com validação JavaScript e não envia dados para um servidor.
